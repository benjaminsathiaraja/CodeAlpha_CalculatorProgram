# 🧮 CodeAlpha Simple Calculator

This project is a simple console-based calculator developed using the **C programming language** 💻. The program allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, division, and modulus.

---

## 📌 About the Program

The calculator takes two integer inputs from the user along with an arithmetic operator. Based on the operator entered, the program performs the corresponding mathematical operation using a `switch-case` statement and displays the result.

### ✅ Supported Operators

- `+` → Addition ➕
- `-` → Subtraction ➖
- `*` → Multiplication ✖️
- `/` → Division ➗
- `%` → Modulus 📊

If the user enters an invalid operator, the program displays an error message ❌.

## ⚙️ How the Program Works

1. The user enters the first number 🔢
2. The user enters the second number 🔢
3. The user selects an operator ➕➖✖️➗
4. The program checks the operator using `switch-case` 🔄
5. The corresponding operation is performed ⚙️
6. The result is displayed on the screen 📺
